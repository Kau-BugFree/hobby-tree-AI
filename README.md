## 세션 이행과 복구

새 버전은 새 DB로 시작합니다. 구형 DB를 도입할 경우 원본이 아닌 SQLite backup API로 만든 복제본을 `COACH_DATABASE_PATH`에 지정하세요. 구형 세션은 읽을 때 정규화하고 다음 성공 저장 때 v2로 저장합니다. 알 수 없는 미래 버전은 409로 거부합니다. 기존 요청 캐시는 유지합니다.

`dialogue_issues` 테이블이 추가되며 세션·문제 스냅샷·응답 캐시·진단은 같은 응답 트랜잭션에 저장합니다. SQLite WAL 사용 중 DB 파일 하나만 복사하지 마세요. 서버를 정지하거나 `sqlite3.Connection.backup()`을 사용합니다. 구버전으로 복구할 때는 코드와 구형 DB 백업을 함께 복구하고, 개선 버전에서 생긴 DB는 별도로 보존하세요.

설계·작업 기록과 실제 검증 범위는 `docs/superpowers/`, `docs/IMPLEMENTATION.md`, `docs/VALIDATION.md`에 있습니다.
